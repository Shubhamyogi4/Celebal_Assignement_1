# Python Data Exploration and Cleaning Assignment

This project demonstrates basic data exploration and cleaning using Python and Pandas in Jupyter Notebook.

## Tasks Performed
- Loaded CSV dataset using Pandas
- Explored dataset (head, tail, shape, columns, data types)
- Handled missing values
- Filtered rows and selected columns
- Removed duplicate values
- Created derived column: total_amount
- Saved cleaned dataset as a new CSV file

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Files Included
- Celeal_Assignment_1.ipynb
- Cleaned CSV dataset
- README.md

## Outcome
Learned basic data analysis and data cleaning techniques using Pandas.
